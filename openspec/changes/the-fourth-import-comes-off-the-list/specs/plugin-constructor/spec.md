## ADDED Requirements

### Requirement: Четвёртый модуль перестаёт грузить базу при импорте

Модуль каркаса, обращающийся к базе только внутри функций, SHALL брать менеджер
внутри них и SHALL быть вычеркнут из списка долга в том же изменении.

#### Scenario: Проверка здоровья

- **WHEN** импортируется модуль страниц и проверок здоровья
- **THEN** база не загружается, а проверка получает её при вызове
