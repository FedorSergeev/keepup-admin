## Why

Журнал событий — таблица, запись, чтение, срок хранения — принадлежит
возможности аудита, а лежал модулем базового пакета. Перенос откладывался дважды:
сначала проверка владения не видела объявление вне схемы, затем проверки читали
исходник по пути. Оба прибора поставлены, перенос повторён.

## What Changes

- `keepup/events.py` уезжает в `packages/keepup-audit/keepup_audit/events.py`;
  `keepup.events` отвечает через слой совместимости (карта переезда знала это имя
  с keepup-114), десять импортёров не меняются.
- Модуль берёт таблицы и менеджер из дистрибутивов, `retention` — из каркаса.
- Запись вычеркнута из списка долга импорта.
