## ADDED Requirements

### Requirement: Каталог разделов заводится из файла, названного приложением

Каталог разделов панели и выдачи ролей SHALL заводиться из файла, названного
приложением в `KeepupSettings.plugins_config_path`, а не из умолчания.
`init_db()` SHALL принимать этот путь аргументом для приложения, которое зовёт
его до `create_app()`, и SHALL читать названный приложением путь, когда
аргумента нет. Старт приложения SHALL досыпать каталог из названного файла.
Заведение SHALL быть идемпотентным: пишутся только строки, которых в базе нет,
и то, что изменил администратор, SHALL оставаться. Отсутствующий файл SHALL
быть записан в журнал и SHALL NOT мешать старту.

#### Scenario: Приложение назвало другой файл

- **WHEN** приложение задало `plugins_config_path` на файл, объявляющий раздел и выдачу роли, и стартовало
- **THEN** раздел и выдача роли есть в каталоге базы, а панель их показывает

#### Scenario: Приложение ничего не назвало

- **WHEN** приложение не задавало путь
- **THEN** каталог читается из `config/modules.json`, как и прежде

#### Scenario: Файла по названному пути нет

- **WHEN** приложение назвало путь, по которому файла нет
- **THEN** в журнале предупреждение, сервер стартует, разделы каркаса на месте

#### Scenario: Изменение администратора

- **WHEN** администратор снял раздел с роли, а затем приложение стартовало снова
- **THEN** выдача не возвращается: заведение не переписывает то, что уже есть
