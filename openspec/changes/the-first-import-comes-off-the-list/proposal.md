## Why

Список из тридцати трёх модулей, берущих базу при импорте, — это долг, и
единственный способ его отдать: по модулю, с вычёркиванием записи в том же
изменении. Первый — самый маленький: `retention.py` берёт менеджер ровно в одном
месте, внутри одной функции.

## What Changes

- `retention.py`: менеджер берётся в функции, которая им пользуется, а не при
  импорте модуля; запись вычеркнута из списка долга.
- Проверки: список долга зелёный, проверки срока хранения событий и метрик
  зелёные.
