## ADDED Requirements

### Requirement: Модуль, которому база нужна при вызове, не грузит её при импорте

Модуль каркаса, обращающийся к базе только внутри функций, SHALL брать менеджер
внутри этих функций и SHALL быть вычеркнут из списка долга в том же изменении.

#### Scenario: Срок хранения

- **WHEN** импортируется модуль срока хранения
- **THEN** база не загружается, а вызов, которому она нужна, получает её сам
