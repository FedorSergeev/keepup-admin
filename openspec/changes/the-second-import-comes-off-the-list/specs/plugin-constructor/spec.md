## ADDED Requirements

### Requirement: Второй модуль перестаёт грузить базу при импорте

Модуль каркаса, обращающийся к базе только внутри функций, SHALL брать менеджер
внутри них и SHALL быть вычеркнут из списка долга в том же изменении.

#### Scenario: Срок хранения снимков

- **WHEN** импортируется модуль срока хранения метрик
- **THEN** база не загружается, а чистка получает её при вызове
