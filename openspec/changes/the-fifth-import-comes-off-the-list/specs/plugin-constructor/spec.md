## ADDED Requirements

### Requirement: Пятый модуль перестаёт грузить базу при импорте

Модуль каркаса, обращающийся к базе только внутри функций, SHALL брать менеджер
внутри них и SHALL быть вычеркнут из списка долга в том же изменении.

#### Scenario: Позиционные параметры

- **WHEN** импортируется помощник позиционных параметров
- **THEN** база не загружается, а функция, которой она нужна, получает её сама
