## ADDED Requirements

### Requirement: Подстановка перенаправляет и запись

Подстановка уехавшего модуля SHALL перенаправлять присваивание атрибута самому
модулю, а не хранить его у себя: проверка, подменяющая атрибут перенесённого
модуля, SHALL влиять на код, который этим модулем пользуется.

#### Scenario: Подмена атрибута

- **WHEN** проверка подменяет атрибут уехавшего модуля через старое имя
- **THEN** перенесённый модуль видит подмену
