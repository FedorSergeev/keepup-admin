# Ядро конструктора: решения

Решения, которые не выводятся из кода и потому записаны здесь. Полный договор —
`doc/plugin_constructor.md`; здесь — то, что касается задачи keepup-101.

## Почему реестр служб, а не контейнер

Задача выглядит спринговой: условная сборка, жизненный цикл, службы с
контрактами, профили. Но в Python контейнер уже есть — это `import`, и второй
контейнер даёт второй ответ на вопрос «что сейчас запущено», причём ответ,
который нельзя прочитать, а можно только выполнить. Поэтому берутся три идеи из
трёх разных мест и ни одна из них не тянет за собой контейнер: порядок
объявления из реестра приложений Django, `provide`/`require` из реестра служб
OSGi, вклад как вызов из спецификаций хуков `pluggy`. Разбор альтернатив —
раздел 14 спецификации.

## Почему две фазы разрешения

Решение администратора о плагинах лежит в таблице `plugin_overrides`, таблица —
в базе, а база — сама плагин. Разрешить это одним проходом нельзя: либо база
нужна раньше, чем решено, какие плагины её поднимают, либо решение
администратора читается молча и теряется, когда база недоступна (так это и
работает в 0.3.0 — `plugins/admin.py:65-78` глотает ошибку). Отсюда фаза 1 —
встроенный каталог, файл приложения и окружение, и фаза 5 — решение
администратора, после того как источник данных поднялся.

## Почему `wants` отдельно от `requires`

Без этого различия каждая возможность требует все остальные (конструктор снова
становится монолитом), либо недостача проглатывается и панель показывает
половину правды молча. `wants` — третье: плагин запускается, отчёт помечает его
`degraded` и называет службу, которой не хватило.

## Почему обязательный плагин нельзя выключить окружением, но можно файлом

Окружение принадлежит стенду и меняется без ревью: переменная, которой можно
выключить источник данных, — это способ уронить стенд одной строкой в панели
развёртывания, причём молча, потому что решение принимается там же, где
читается. Файл приложения — корень композиции: он ревьюится и commитится, и
именно им приложение говорит «у меня свой источник данных, не поднимай
встроенный». Панель не решает про обязательные вовсе.
