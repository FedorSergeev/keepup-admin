## 1. Дескриптор и требования

- [x] 1.1 `keepup/kernel/descriptor.py`: `PluginDescriptor` (id, name, version,
  distribution, priority, requires, wants, provides, contributions, kind,
  default_enabled, config_schema), `Requirement` и разбор `"datasource>=1"`.
  Проверка: `kernel_tests.py` — дескриптор читается с класса, не создавая
  плагина; `"datasource>=1"`, `"datasource"` и `"datasource >= 1"` разбираются
  одинаково.
- [x] 1.2 Плагин без дескриптора принимается как плагин 0.3.0: id из имени
  файла, требования пусты, вид `optional`. Проверка: `kernel_tests.py` —
  плагин без `descriptor` грузится, запускается и не требует ничего.

## 2. Каталог

- [x] 2.1 `keepup/kernel/catalogue.py`: чтение файла, слияние встроенного
  каталога с файлом приложения по полям, применение профиля. Проверка:
  `kernel_tests.py` — поле из файла приложения побеждает, остальные поля
  встроенной записи сохраняются.
- [x] 2.2 Профиль не может включить плагин, которого в каталоге нет, и не
  может выключить обязательный. Проверка: `kernel_tests.py` — `CatalogueError`
  на неизвестный id; обязательный остаётся включённым.
- [x] 2.3 `keepup/plugins/builtin.json` — встроенный каталог каркаса.
  Проверка: `kernel_tests.py` — файл читается, каждый объявленный id имеет вид.

## 3. Реестр служб

- [x] 3.1 `keepup/kernel/services.py`: `provide`/`require` с версией, ленивый
  провайдер, `freeze()`, отчёт. Проверка: `kernel_tests.py` — служба отдаётся
  потребителю, версия ниже требуемой не отдаётся, ленивая фабрика вызывается
  один раз.
- [x] 3.2 Два провайдера одной обязательной службы — отказ с именами обоих.
  Проверка: `kernel_tests.py` — `DuplicateProvider` на `freeze()`.

## 4. Загрузчик

- [x] 4.1 `keepup/kernel/loader.py`: загрузка из каталога плагинов приложения
  (файл на id, класс `f"{id.capitalize()}Plugin"`) и через точку входа группы
  `keepup.plugins`. Проверка: `kernel_tests.py` — файл, класс, отсутствие файла
  и отсутствие класса дают четыре разных исхода.
- [x] 4.2 Дискавери не импортирует пакеты возможностей: только то, что
  объявлено в каталоге или найдено точкой входа. Проверка: `kernel_tests.py` —
  точка входа подставляется, содержимое `sys.modules` не меняется.

## 5. Жизненный цикл

- [x] 5.1 `keepup/kernel/lifecycle.py`: `Runtime` и `create_runtime(settings)` —
  фаза обязательных, регистрация служб, инициализация по требованиям, фаза
  необязательных с решением администратора, остановка в обратном порядке.
  Проверка: `kernel_tests.py` — плагин пользуется службой другого плагина
  независимо от порядка объявления; `cleanup()` вызывается в обратном порядке.
- [x] 5.2 `wants` не останавливает плагин: он запускается, отчёт несёт пометку
  `degraded` с именем недостающей службы. Проверка: `kernel_tests.py`.
- [x] 5.3 Обязательный плагин, названный в `PLUGINS_DISABLE`, останавливает
  старт; названный в файле приложения — выключается. Проверка:
  `kernel_tests.py`.
- [x] 5.4 Состояние ядра — на экземпляре: два ядра в одном процессе не делят
  решения и службы. Проверка: `kernel_tests.py`.
