## Why

Записанный порядок переноса требовал, чтобы базовый пакет объявил дистрибутив, из
которого реэкспортирует имя. Это невозможно: каждый дистрибутив зависит от
`keepup-admin` ради конструктора, которым загружается, — обратное ребро дало бы
зависимость в обе стороны, и ни один из двух нельзя было бы поставить отдельно.

## What Changes

- Порядок исправлен: имя **убирается** из базового пакета, а не реэкспортируется;
  базовый пакет не объявляет ни одного дистрибутива; развёртывание ставит те
  возможности, которые называет.
- Слой совместимости называет то, что можно сделать: если дома нет, приложение
  получает `keepup.db moved to keepup_db: install keepup-db`, а не загадку про
  отсутствующий модуль.
- Проверки: базовый пакет не зависит ни от одного дистрибутива; документ
  утверждает именно это; подстановка называет дистрибутив.
