## ADDED Requirements

### Requirement: Ни один модуль каркаса не грузит базу при импорте, кроме объявляющих таблицы

Модуль каркаса, обращающийся к базе только внутри функций, SHALL брать менеджер
внутри них. Единственные модули, которым база нужна при импорте, — те, что
объявляют таблицы, и они уезжают в дистрибутивы своих возможностей (keepup-124),
что проверка и называет.

#### Scenario: Список долга пуст

- **WHEN** проверяется, какие модули берут базу при импорте
- **THEN** остаются только объявляющие таблицы, и у каждого назван дистрибутив
