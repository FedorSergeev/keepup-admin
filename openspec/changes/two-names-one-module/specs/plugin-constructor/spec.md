## ADDED Requirements

### Requirement: Старое и новое имя уехавшего модуля — один объект

Подстановка SHALL давать уехавшему подмодулю его старое имя, ссылаясь на **тот
же** объект модуля, а не строя второй из того же файла, чтобы настройка,
записанная через одно имя, была видна коду, читающему другое.

#### Scenario: Настройка через старое имя

- **WHEN** код пишет атрибут модуля через старое имя
- **THEN** код, читающий новый модуль, видит записанное
