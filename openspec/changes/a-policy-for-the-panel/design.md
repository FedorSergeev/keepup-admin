# Политика панели: решения

## Почему `script-src 'self'` без хеша и nonce

Страницы панели — статические файлы, которые отдаёт `FileResponse`, а разделы
подключаются динамически. Nonce пришлось бы вписывать в каждый ответ (то есть
переписывать HTML на лету), хеш — пересчитывать при каждой правке и для каждой
копии страницы у приложения. Оба варианта делают политику хрупкой ровно в том
месте, где она нужна. Поэтому встроенного скрипта в страницах каркаса не
осталось вовсе: bootstrap узкой раскладки уехал в
`static/js/layout_bootstrap.js`, а действия разметки — в реестр.

## Почему `style-src` оставляет `'unsafe-inline'`

Разделы выставляют стили из данных (ширина полосы, тон метки), Tailwind строит
правила в `<style>` во время работы, AOS двигает элементы инлайн-стилями.
Вынести это в файлы нельзя, не переписав разделы. Стиль не читает cookie сессии
и не отправляет её никуда, поэтому это дверь на порядок меньше скриптовой;
задача (остаток находки 18) — про исполнение скрипта.

## Что делает реестр действий

Раздел регистрирует обработчики и называет их в разметке:

```js
KeepupActions.register({
    'users.roles': (element) => showUserRolesModal(Number(element.dataset.userId)),
});
```

```html
<button data-action="users.roles" data-user-id="7">Roles</button>
```

Один слушатель на документе обслуживает все разделы, включая загруженные позже,
поэтому перерисовка таблицы не требует перепривязки. Разметка может назвать
действие, но не функцию: имя, которого никто не регистрировал, не делает
ничего. События разведены по смыслу — форма отвечает на `submit`, поле на
`change`, ссылка и кнопка на `click`; клик по кнопке внутри формы, чьё действие
висит на форме, не запускает обработчик второй раз.

## Почему Report-Only в настройках

Разделы приложения тоже держатся на встроенных обработчиках (в репозитории
приложений — около сорока файлов). Обновление каркаса не может переписать их
через границу зависимости, поэтому `csp_report_only=True` даёт приложению
увидеть, что политика отвергла бы, и перевести разделы без выключения панели.

## Почему страница перепроверяется браузером

`GatedStaticFiles` давно просит браузер перепроверять скрипты и стили
(`Cache-Control: no-cache`), а сама страница оставалась на выдуманной браузером
свежести — 10% возраста файла. Страница, закэшированная до обновления, несёт
встроенные обработчики, которые новая политика отвергает; поэтому страницы
панели получают тот же заголовок.
