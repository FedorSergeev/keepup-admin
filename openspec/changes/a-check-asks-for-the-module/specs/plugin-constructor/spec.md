## ADDED Requirements

### Requirement: Проверка спрашивает модуль, а не путь

Проверка, которой нужен исходник модуля каркаса, SHALL спрашивать файл у самого
модуля (`source_of`), чтобы модуль, уехавший в дистрибутив и отвечающий через
слой совместимости, оставался проверяемым.

#### Scenario: Модуль уехал

- **WHEN** модуль, который читает проверка, перенесён в дистрибутив
- **THEN** проверка читает его по старому имени и продолжает проверять то, что
  проверяла
