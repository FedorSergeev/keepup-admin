## Why

Объявление таблицы уезжает из схемы ядра вместе с модулем, который её ведёт
(keepup-124). Переносить двенадцать объявлений без карты «кто чей» — значит
переносить их вслепую; карта, которую никто не проверяет, расходится с кодом
через неделю.

## What Changes

- `doc/table-ownership.md`: у каждой объявленной таблицы ровно один владелец —
  дистрибутив возможности, куда объявление уедет; для трёх таблиц владелец
  назван, хотя дистрибутив появится в 0.5.0.
- `tests/table_ownership_tests.py`: каждая объявленная таблица названа; карта не
  называет несуществующих таблиц; владелец — дистрибутив или названная поздняя
  работа; уже уехавшие таблицы не объявлены в схеме ядра дважды.
