## Why

Обещание выпуска — `keepup-admin` плюс драйвер это развёртывание, которое
говорит с базой и не несёт ни одной библиотеки, которой не пользуется: ни
SQLAlchemy, ни драйвера PostgreSQL, ни хешировщика паролей, ни JWT. Код, которому
они нужны, в 0.4.0 ещё лежит в базовом пакете и уезжает остатком keepup-124,
поэтому зафиксировать сейчас — и не дать сломать, пока перенос идёт, — можно
границу: сам конструктор, ядро, не импортирует ни одну из них.

## What Changes

- `tests/base_package_freedom_tests.py`: ядро не импортирует ни одной из четырёх
  библиотек; у каждой есть дистрибутив, который её примет; базовый пакет всё ещё
  объявляет их, и это записанный долг (проверка удаляется вместе с последним
  куском переноса); ядро не импортирует модуль возможности.
