## ADDED Requirements

### Requirement: Приложение поднимает каталог вместе с собой

`create_app` SHALL поднимать рантайм (каталог, профиль, две фазы) в своём
lifespan и SHALL закрывать его при остановке. Каталог, который не может
запуститься, SHALL NOT мешать приложению работать: причина SHALL попадать в
журнал, и приложение SHALL обслуживать запросы.

#### Scenario: Каталог не поднимается

- **WHEN** каталог развёртывания не может запуститься
- **THEN** приложение работает, а причина записана в журнал

#### Scenario: Приложение останавливается

- **WHEN** приложение завершает работу
- **THEN** службы, опубликованные возможностями, закрыты вместе с ним
