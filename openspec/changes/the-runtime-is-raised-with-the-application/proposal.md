## Why

Каталог и профили работали только в проверках: `create_app` собирал приложение
старым путём, и возможности, которые уже умеют объявлять свои таблицы и отдавать
службы, в развёртывании не участвовали. Из-за этого объявление нельзя унести из
`keepup.schema` (keepup-124) — таблица перестала бы создаваться.

## What Changes

- `create_app` поднимает рантайм в своём lifespan: каталог (встроенный + каталог
  приложения + профиль), две фазы, службы и создание объявленных таблиц — рядом
  со старым путём, который продолжает регистрировать маршруты и годится для
  плагинов 0.3.0.
- Каталог, который не может запуститься, **не роняет приложение**: причина
  пишется в журнал, приложение работает — у развёртываний 0.3.0 каталога нет
  вовсе.
- Рантайм закрывается вместе с приложением; у рантайма появился публичный ответ
  `started`.
