## ADDED Requirements

### Requirement: Список держателей библиотеки записан и проверяется

Документ SHALL называть модули базового пакета, которые импортируют каждую
библиотеку, которую база объявляет своей зависимостью. Библиотека, которую не
импортирует ни один модуль, SHALL быть названа с причиной, по которой она всё ещё
нужна. Модуль-держатель, не названный в документе, SHALL считаться ошибкой.

#### Scenario: Модуль уехал

- **WHEN** модуль, державший библиотеку, переехал в дистрибутив
- **THEN** он исчезает из таблицы, и проверка требует обновить её в том же
  изменении

#### Scenario: Библиотека без импортёров

- **WHEN** библиотека нужна базе, но ни один модуль её не импортирует
- **THEN** документ называет её и причину, а не молчит о ней
