## ADDED Requirements

### Requirement: Седьмой модуль перестаёт грузить базу при импорте

Модуль каркаса, обращающийся к базе только внутри функций, SHALL брать менеджер
внутри них и SHALL быть вычеркнут из списка долга в том же изменении.

#### Scenario: Реестр реплик

- **WHEN** импортируется модуль реестра реплик
- **THEN** база не загружается, а функции, которым она нужна, получают её сами
