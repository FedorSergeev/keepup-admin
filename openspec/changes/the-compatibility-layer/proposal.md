## Why

0.4.0 переносит код из базового пакета в дистрибутивы рядом с ним: язык таблиц
уезжает из `keepup.tables`, пул — из `keepup.db`, вход — из `keepup.auth`.
Приложение, которое импортирует старое имя, обязано проработать ещё выпуск — и
обязано узнать, куда имя уехало: молчаливая подмена это и есть способ пришпилить
приложение к выпуску, из которого нельзя выйти.

## What Changes

- `keepup/compat.py`: карта «старое имя → куда уехало» (`MOVED`), предупреждение
  один раз на процесс (`warn_moved`), подстановка, которая отвечает как новый
  модуль (`shim`), и установка подстановок для имён, которых больше нет
  (`install`).
- `keepup/__init__.py` устанавливает слой при импорте пакета: пока модуль на
  месте, ничего не подменяется.
