## ADDED Requirements

### Requirement: Долг импорта измерен и только сокращается

Проверка SHALL вести поимённый список модулей, берущих базу при импорте, с
причиной у каждого. Модуль вне списка SHALL считаться ошибкой, модуль из списка,
переставший брать базу, — тоже. Ядро SHALL NOT брать базу при импорте ни в одном
модуле.

#### Scenario: Новый импорт

- **WHEN** модуль вне списка начинает брать базу при импорте
- **THEN** проверка падает и называет модуль

#### Scenario: Модуль перестал

- **WHEN** модуль из списка перестал брать базу при импорте
- **THEN** проверка падает и просит вычеркнуть запись
