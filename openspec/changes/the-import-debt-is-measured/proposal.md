## Why

`doc/distributions.md` называл четыре модуля, чей импорт тянет базу. Проверка,
написанная по этому списку, показала настоящий размер: **тридцать три** модуля
каркаса берут менеджер базы (а частью и SQLAlchemy) уже при импорте. Это и есть
подлинный объём обещания «база не несёт библиотек для базы»: пока импорт любого
из них грузит базу, развёртывание без хранилища невозможно, и переносить модуль
некуда.

## What Changes

- `tests/lazy_database_import_tests.py`: поимённый список модулей, которым пока
  можно брать базу при импорте, с причиной у каждого; список может только
  сокращаться; ядро (`keepup/kernel`) не берёт базу ни в одном модуле.
- Долг измерен и записан, а не оценён на глаз.
